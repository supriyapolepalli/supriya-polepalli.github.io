## Publish with GitHub Pages

1. github.com → **+** → **New repository**.
2. Name it `YOUR-GITHUB-USERNAME.github.io` · **Public**.
3. **Add file → Upload files**: upload `index.html` and this `README.md`. Commit.
4. **Settings → Pages → Build and deployment**: *Deploy from a branch* → `main` → `/ (root)` → **Save**.
5. After 1–2 minutes the site is live at `https://YOUR-GITHUB-USERNAME.github.io`.

## Before you publish

- Open `index.html`, search for `YOUR-GITHUB-USERNAME`, and replace it (3 places).
- Make sure every number matches your resume and LinkedIn exactly.
- Add a demo link or screenshots to the OppPulse AI case study.
